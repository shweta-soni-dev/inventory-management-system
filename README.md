# 📦 Inventory Management System

A complete Java Swing based desktop application to manage inventory, users, products, customers, and orders using MySQL.

---

## 🚀 Features

- Login System
- User Management
- Category Management
- Product Management
- Customer Management
- Order Processing
- Order History
- Database Integration
- Logout System

---

## 🛠 Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- NetBeans IDE

---

## 🗄 Database

MySQL database with tables:

- appuser
- category
- product
- customer
- orderdetail


 ▶ How to Run

1. Clone repository:
   git clone https://github.com/shweta-soni-dev/inventory-management-system.git
 
2. Open in NetBeans

3. Configure MySQL connection

4. Run:
