 📦 Inventory Management System

A complete Java Swing based desktop application to manage inventory, users, products, customers, and orders using MySQL.

---

## 🚀 Features

- Login System
- User Management
- Category Management
- Product Management
- Customer Management
- Order Processing
- Order History
- Database Integration
- Logout System

---

## 🛠 Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- NetBeans IDE

---

## 🗄 Database

MySQL database with tables:

- appuser
- category
- product
- customer
- orderdetail
